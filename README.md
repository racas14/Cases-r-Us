Explain what this project does? - 

This project has been made to ensure a reliable and safe way to provide for good entertainment and a safe transactional service. What this project does is let users who play the game, 
have a safe market where they can sell their skins and partake in trading, not only does the project contain this but it also acts like an inventory system, allowing you to store your skins and knives in a safe and 
reliable place where they cannot be hacked into or stolen.

Describe the value it provides to its users - 

For someone like Jake, he wanted to be able to import his CS inventory into the system automatically without having to individually adding the skins by hand, 
with our system this is a feature, instead of having to select every skin you want one by one you can select all with a button or in bulk. Not only that but you can also see any transactions that are in place
which also aligns with his second value.

As for Ryan he wanted to be able to track case prices which is actually a standard feature that comes with the trading, all skins are market priced and the same goes for cases, he'll be able to track all prices in realtime.
Not only this, but the website has a comparison stat which looks at other websites with a similar premises, and compares all prices and shows the user too, this will ensure that they are getting the best prices possible out of every 
website which would make him use it more. Another feature that Ryan wanted was to be able to export inventory data into excel and have a spreadsheet, luckily for him there's a feature in settings to export all data, all data since 
he made his account would be on the excel page, this would allow for a deeper analysis and he will be able to calculate his win loss ratio in the long term.
